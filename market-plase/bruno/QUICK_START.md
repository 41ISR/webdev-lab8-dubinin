# Bruno - Быстрый старт

## Что это?

Bruno - это API клиент (как Postman), но файлы хранятся в вашем репозитории.

## Установка

1. Скачайте: https://www.usebruno.com/
2. Установите
3. Запустите Bruno

## Открытие коллекции

### Вариант 1: Через меню
1. File → Open Collection
2. Выберите папку `market-plase/bruno-collection`

### Вариант 2: Перетаскивание
Перетащите папку `bruno-collection` в окно Bruno

## Настройка

1. В правом верхнем углу выберите **"Production"**
2. Готово! Переменные уже настроены

## Первый запрос

1. В левой панели откройте **Auth → Register**
2. Измените username в Body (если хотите)
3. Нажмите **"Send"** (или Ctrl+Enter)
4. Токен автоматически сохранится!

## Порядок тестирования

### 1. Регистрация
**Auth → Register**
- Измените username/password
- Send
- Токен сохранится автоматически

### 2. Просмотр товаров
**Items → Get All Items**
- Просто нажмите Send
- Увидите все товары

### 3. Создание товара
**Items → Create Item**
- Измените данные в Body
- Send
- ID товара сохранится в переменную `itemId`

### 4. Просмотр ставок
**Bids → Get Item Bids**
- Использует сохраненный `itemId`
- Send

### 5. Создание ставки (нужен второй пользователь!)
**Сначала**: Auth → Register с другим username
**Потом**: Bids → Create Bid
- Измените amount (должен быть выше текущей ставки)
- Send

### 6. Мои ставки
**Bids → Get My Bids**
- Send
- Увидите все ваши ставки

### 7. Статистика
**Stats → Get Stats**
- Send
- Общая статистика платформы

## Переменные

Используются автоматически:
- `{{baseUrl}}` = https://kitek.ktkv.dev/marketplace
- `{{token}}` = ваш JWT токен (заполняется после Login/Register)
- `{{itemId}}` = ID последнего созданного товара

### Просмотр переменных
1. Клик на "Environments" (правый верхний угол)
2. Выберите "Production"
3. Увидите все переменные

### Ручное изменение
1. Откройте Production environment
2. Измените значение
3. Ctrl+S для сохранения

## Структура коллекции

```
📁 Auth (Аутентификация)
  📄 Register - Регистрация
  📄 Login - Вход
  📄 Get Me - Текущий пользователь

📁 Items (Товары)
  📄 Get All Items - Список товаров
  📄 Create Item - Создать товар
  📄 Delete Item - Удалить товар

📁 Bids (Ставки)
  📄 Get Item Bids - Ставки на товар
  📄 Create Bid - Создать ставку
  📄 Get My Bids - Мои ставки

📁 Stats (Статистика)
  📄 Get Stats - Статистика платформы
```

## Вкладки в запросе

### Body
Тело запроса (JSON). Здесь вводите данные для POST запросов.

### Auth
Тип авторизации:
- **None** - для публичных запросов
- **Bearer Token** - для защищенных (использует `{{token}}`)

### Docs
Документация запроса с примерами

### Tests
Автоматические тесты. После Send увидите результаты внизу:
- ✅ Зеленая галочка = тест прошел
- ❌ Красный крестик = тест не прошел

## Горячие клавиши

- **Ctrl+Enter** - отправить запрос
- **Ctrl+S** - сохранить
- **Ctrl+N** - новый запрос
- **Ctrl+F** - поиск

## Типичные ошибки

### 401 Unauthorized
❌ Не авторизованы
✅ Выполните Login заново

### 403 Forbidden
❌ Недействительный токен
✅ Выполните Login заново

### 400 Bad Request
❌ Неверные данные
✅ Проверьте Body запроса

### 404 Not Found
❌ Товар не найден
✅ Проверьте itemId

### Переменная не подставляется
❌ Не выбрано окружение
✅ Выберите "Production" в правом верхнем углу

## Полезные функции

### Запуск всех запросов папки
1. Правый клик на папке (например, Auth)
2. "Run Folder"
3. Все запросы выполнятся по очереди

### Дублирование запроса
1. Правый клик на запросе
2. "Duplicate"

### Создание нового запроса
1. Правый клик на папке
2. "New Request"

## Автоматическое сохранение данных

После некоторых запросов данные сохраняются автоматически:

**Register/Login** → сохраняет `token`
```javascript
if (res.body.token) {
  bru.setEnvVar("token", res.body.token);
}
```

**Create Item** → сохраняет `itemId`
```javascript
if (res.body.id) {
  bru.setEnvVar("itemId", res.body.id);
}
```

## Пример полного цикла

1. **Register** → получаете токен
2. **Create Item** → создаете товар, получаете itemId
3. **Get Item Bids** → смотрите ставки (пока пусто)
4. **Register** (второй пользователь) → новый токен
5. **Create Bid** → делаете ставку на товар первого пользователя
6. **Get My Bids** → видите свою ставку
7. **Get Item Bids** → видите ставку в истории товара
